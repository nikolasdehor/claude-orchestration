# Contributing

Contribuições são bem-vindas.

## Regras

- Abra um issue antes de PR grande. PRs pequenos e focados são preferidos.
- **Nunca** use em dashes (U+2014 ou U+2013) em texto. Use hífen simples (-) ou vírgula.
- Se estiver em dúvida sobre escopo, pergunte no issue antes de codar.
- Mantenha o estilo bilíngue (pt-BR + EN) nos arquivos públicos.

## O que aceita

- Novos exemplos antes/depois em EXAMPLES.md (um princípio, um exemplo real).
- Correções de clareza, ortografia, estrutura.
- Traduções para outros idiomas (arquivo separado, `README.<lang>.md`).

## O que não aceita

- Princípios novos sem caso real de produção que os motive.
- Reescritas estilísticas que não agregam valor.
- Mudanças que inflam o texto. Esta é uma lista enxuta por escolha.

# Contributing (English)

Contributions welcome.

## Rules

- Open an issue before large PRs. Small, focused PRs are preferred.
- **Never** use em dashes (U+2014 or U+2013) in text. Use plain hyphen (-) or comma.
- If unsure about scope, ask in the issue before coding.
- Keep the bilingual style (pt-BR + EN) in public files.

## Accepted

- New before/after examples in EXAMPLES.md (one principle, one real case).
- Clarity, spelling, structure fixes.
- Translations to other languages (separate file, `README.<lang>.md`).

## Not accepted

- New principles without a real production case motivating them.
- Stylistic rewrites that do not add value.
- Changes that inflate the text. This is a lean list by design.
